HeartStone design reference

Static design pages for the public website and the citizen dashboard. They link together, so you can click through the whole journey in a browser.

Not production code. Sample content only. These pages define layout, content and behaviour for the React build. See README.md for the rules they encode and what still needs backend work or sign-off.

Start the journey at the website homepage

The journey

  1. Website homepage: search, the three doors, life events and topics
  2. A service page: what you need and what happens next, then "Sign in to apply"
  3. Sign in: continue with the national digital ID
  4. Citizen dashboard: applications, payments, documents, messages and "My government"
  5. Signed out: "Sign out" in the dashboard returns to the website
